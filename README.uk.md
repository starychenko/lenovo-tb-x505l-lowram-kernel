# Low-RAM ядро для Lenovo TB-X505L

Це перевірене ядро Linux 4.9.337 для Lenovo Tab M10 HD TB-X505L з 2 ГБ
RAM. r7 лишається стабільним варіантом для відкату. r8-c3 вже пройшов
тимчасове і постійне завантаження та додає Binder-кеші, compat vDSO32,
мережеві/KCAL можливості, а також scheduler, memory та I2C fast paths.

[Встановлення](docs/INSTALL.uk.md) · [Збірка](docs/BUILD.md) · [Розробка r8](docs/R8_ENGINEERING.md) · [Динаміка швидкодії](docs/PERFORMANCE_DYNAMICS.md) · [Розробка r7](docs/R7_ENGINEERING.md) · [Логи Camera HAL](docs/CAMERA_HAL_LOGGING.md)

r8-c3 є pre-release кандидатом: він пройшов автоматичні, навантажувальні та
апаратні тести, постійно прошитий на тестовому планшеті, а readback
boot-розділу точно збігся з перевіреним образом.

## Для якого пристрою

Фізично перевірено лише на такій конфігурації:

- Lenovo TB-X505L, 2/32 ГБ;
- Snapdragon 429 / SDM439;
- vendor `TB-X505L_S001149_221018_ROW`;
- crDroid 9.10 PHH GSI, Android 13;
- розблокований bootloader.

Не прошивайте цей образ на TB-X505F, TB-X505X або іншу збірку vendor без попереднього `fastboot boot`. Спочатку зробіть власну копію boot-розділу. Заводський boot і пропрієтарні Lenovo-модулі в репозиторії не публікуються.

## Що покращено

- Ядро поетапно оновлено з 4.9.205 через CAF 4.9.206/4.9.227 до 4.9.337.
- Увімкнено PSI, memory cgroups і swap accounting.
- Android `lmkd` реально слухає `/proc/pressure/memory` і реагує на фактичний тиск пам'яті.
- Старий kernel low-memory-killer вимкнено, щоб він не конфліктував з userspace `lmkd`.
- Увімкнено KSM.
- zRAM 1 ГБ працює на LZ4 замість LZO за замовчуванням.
- Для цього пристрою встановлюється `vm.page-cluster=0`.
- Виправлено reclaim compound pages у `fs/proc/task_mmu.c`.
- Збережено точні заводські Lenovo audio/WLAN-модулі та їх ранній порядок завантаження.
- Обхід CRC обмежено списком із 25 конкретних внутрішніх назв модулів.
- Для всіх 25 модулів перевірено 980 унікальних символів; у фінальному r7
  немає жодного відсутнього kernel symbol.
- Відновлено потрібний Lenovo WLAN timer ABI та сумісність зі старою схемою
  Adreno scratch buffer.
- Виправлено життєвий цикл camera PM QoS, який давав kernel warning після
  повторного закриття/відкриття камер.
- Після окремого A/B-тесту I/O планувальником за замовчуванням став `deadline`.
- Є окремий відкатний профіль EAS/schedutil для Android 13; це не прихований
  незворотний твік усередині ядра.
- r8 додає Binder-кеші, 32-бітний compat vDSO, BBR/Westwood, FQ/FQ-CoDel і
  KCAL.
- c3 обмежує sync-wake на зайнятому CPU, зайвий high-order reclaim і
  compaction unevictable-сторінок, а малі I2C-транзакції тача не ганяє через
  дорожчий DMA-шлях.

## Компроміс безпеки

У відкритих вихідних кодах немає приватного ключа, яким Lenovo підписала заводські модулі. Тому примусову перевірку довіреного ключа переведено у permissive-режим. Пошкоджені підписи відхиляються, але користувач з root може завантажити непідписаний модуль. Ядро очікувано має taint `12290`, а модулі позначаються `(OFE)`.

Для платіжного або іншого чутливого пристрою це ядро не рекомендується. Також воно не оновлює старий vendor і його security patch level.

## Що перевірено

- Тимчасове завантаження фінального r7 та запуск після постійної прошивки.
- Усі 25 заводських модулів.
- Звук, Wi-Fi, передня і задня камери, тач, жести й мікрофон.
- PSI, KSM, LZ4 zRAM, `lmkd`.
- Окремі тести CPU, RAM, wake-up latency, direct I/O, запусків програм і
  скролу Settings; результати опубліковано разом з регресіями, без вибіркового
  представлення.
- Реальний цикл Bluetooth OFF -> ON -> OFF, акселерометр і дві камери.
- Повторні цикли обох камер після виправлення PM QoS.
- Точний SHA-256 записаного boot-розділу після прошивки r7.
- Чистий kernel fault scan першого постійного запуску.
- Повний production-validator c3, 512 МіБ memory-pressure і точний readback
  постійного boot-розділу.

Мікрофон тестового планшета працює слабко; поведінка однакова на заводському та новому ядрі, тому ймовірна механічна проблема.

## Швидкий тест

Будь-яке нове ядро спочатку завантажити без запису в boot. Для стабільного r7:

```text
adb reboot bootloader
fastboot boot tb-x505l-lowram-r7-boot.img
```

Після перевірки всього заліза прошити постійно:

```text
adb reboot bootloader
fastboot flash boot tb-x505l-lowram-r7-boot.img
fastboot reboot
```

Повна інструкція з backup і rollback: [docs/INSTALL.uk.md](docs/INSTALL.uk.md).

## Що є в репозиторії та релізі

- точний фінальний конфіг та конфіги проміжних кандидатів;
- повне дерево вихідного коду r7 і перевірені патчі;
- вихідний код власного AArch64-бенчмарку та Android UI-обгорток;
- відкатний інсталятор профілю Android 13;
- скрипти збірки, repack і перевірки;
- повний технічний опис усіх вдалих і невдалих підходів;
- `boot.img`, raw `Image`, `System.map`, `Module.symvers`;
- повний corresponding source archive;
- точні Clang/GCC toolchain-и та матеріали для відтворюваної збірки;
- SHA-256 для всіх артефактів.

Проміжні експериментальні образи не подаються як готові до прошивки. Окремий
релізний архів містить перевірені на приватність технічні докази, результати й
історію кандидатів.
